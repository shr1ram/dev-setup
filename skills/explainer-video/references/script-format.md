# script.json

The single source of truth for a project. Written by hand (by you) after research.

```json
{
  "title": "Why compound interest feels like magic",
  "style": "3b1b",
  "aspect": "16:9",
  "voice": "af_heart",
  "speed": 1.0,
  "lang": "a",
  "subtitles": true,
  "sources": ["https://..."],
  "blocks": [
    {
      "id": "01",
      "narration": "Imagine you lend a friend one hundred dollars...",
      "visual": "Title card. On 'one hundred dollars' a gold coin stack grows from 0 to 100 (counter). On 'ten percent' a small +10 badge pops beside it."
    }
  ]
}
```

This must be plain JSON (no comments): every script `json.loads` it. `example-script.json` is a
complete, valid file to start from.

| field | meaning |
|---|---|
| `style` | `3b1b` \| `welch` \| `econ` \| `paper` (see styles.md) |
| `aspect` | `"16:9"` or `"9:16"` |
| `voice` | Kokoro voice id, see below |
| `speed` | 1.0 normal; 0.9 slower, 1.1 faster |
| `lang` | Kokoro language code: `a` American, `b` British English |
| `subtitles` | burn captions in; scenes then keep content above y = -2.3 (`self.safe_bottom`) |
| `sources` | what the facts came from (goes in the delivery note) |
| `blocks` | the scenes, in order (below) |

## Blocks

- A block is one scene: one visual idea, one continuous narration, usually 15–45 s. Not fixed-length:
  let the idea decide. A 3-minute video is ~6–9 blocks.
- Word budget: Kokoro at speed 0.9 delivers about 2.3-2.6 words/s (technical text runs faster), and each block adds ~1.3 s of padding
  and tail, so plan **~2.1 words per second of target length** (a 60 s video is ~125 words total,
  a 30 s block ~65 words). At speed 1.0 use ~2.4 words/s. `tts.py` prints the real numbers; trim then.
- `id` is two digits, in order. The Manim class for it is `Block01`, `Block02`, ...
- `narration` is exactly what the voice says. Spoken style: contractions, short sentences,
  numbers spelled out when they are read aloud ("two thousand" not "2,000"), no stage directions.
  Prefer full stops to colons/semicolons mid-sentence: Kokoro pauses oddly on them.
- `visual` is a beat sheet for the scene, keyed to narration phrases, because `self.at("phrase", ...)`
  fires animations on those words. Write the phrase exactly as it appears in narration.

## Kokoro voices (English)

American female: af_heart (best, default), af_bella, af_nicole, af_sarah, af_sky
American male:   am_michael, am_adam, am_fenrir, am_puck
British female:  bf_emma, bf_isabella    British male: bm_george, bm_lewis   (set "lang": "b")
Other languages exist (lang e, f, h, i, j, p, z) but word timestamps are English-only;
`self.at()` then falls back to a proportional estimate.
